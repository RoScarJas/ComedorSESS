Proyecto
ComedorSESS

Descripción
Aplicación para la gestión de un comedor.

Funcionalidades
Gestión de usuarios.
Consulta de menús.
Gestión de pedidos.
Administración de información del comedor.

Entradas
Datos de usuarios.
Información de pedidos.
Datos de menús.

Salidas
Confirmaciones de operaciones.
Listados de menús.
Información de pedidos.

Criterios de aceptación
Los usuarios pueden registrarse correctamente.
Los menús se muestran sin errores.
Los datos obligatorios son validados.
Los pedidos se guardan correctamente.
Casos límite
Campos vacíos.
Datos incorrectos.
Búsquedas de registros inexistentes.
